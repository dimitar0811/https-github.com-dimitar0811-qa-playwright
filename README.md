# QA Playwright Automation Project

## Description

This project contains automated UI and API tests using Playwright and TypeScript.

## Technologies

* Playwright
* TypeScript
* Node.js
* Git
* GitHub Actions

## Installation

Clone the repository and install the dependencies:

```bash
git clone https://github.com/dimitar0811/https-github.com-dimitar0811-qa-playwright.git
cd https-github.com-dimitar0811-qa-playwright
npm ci
npx playwright install --with-deps
```

## Running Tests

Run all Playwright tests:

```bash
npx playwright test
```

Run tests with the browser visible:

```bash
npx playwright test --headed
```

Open the HTML test report:

```bash
npx playwright show-report
```
